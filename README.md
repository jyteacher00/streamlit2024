# 아침 등교 QR 마음 출석

Streamlit으로 만든 아침 등교용 마음 출석 웹앱입니다. 학생은 QR 코드로 접속해 최초 1회 학번과 이름을 등록하고, 매일 감정 아이콘과 단답형 질문에 답할 수 있습니다.

## 주요 기능

- 학생용 화면
  - 학번과 이름 최초 1회 등록
  - 같은 기기에서 학생 자동 확인
  - 날짜별 감정 선택 및 오늘의 질문 단답 제출
  - 하루 1회 제출 제한
- 교사용 화면
  - 긍정 감정 10개, 부정 감정 10개 아이콘 노출 여부 설정
  - 매일 바꿀 수 있는 질문 입력
  - `학번`, `이름` 컬럼이 있는 CSV/XLSX 명단 업로드
  - 날짜별 학생 답변 조회
  - 학생별 상담 내용 기록 컬럼 관리
  - 날짜별 답변 CSV 다운로드

## 실행 방법

```bash
streamlit run app.py
```

앱 실행 후 학생에게는 학생용 화면 주소를 QR 코드로 만들어 배포하면 됩니다. 교사는 사이드바에서 `교사용` 화면을 선택해 질문, 감정 아이콘, 명단, 상담 기록을 관리합니다.

## 명단 파일 형식

CSV 또는 XLSX 파일을 업로드할 수 있으며, 첫 번째 행에 다음 컬럼이 필요합니다.

| 학번 | 이름 |
| --- | --- |
| 1 | 김학생 |
| 2 | 이학생 |

영문 컬럼명 `student_id`, `name`도 사용할 수 있습니다.
